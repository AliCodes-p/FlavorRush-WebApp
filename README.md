# FlavorRush 🍔🔥

FlavorRush is a modern full-stack food ordering web application built using React, Flask, and MongoDB Atlas. The project provides a complete restaurant ordering experience including authentication, cart management, checkout, order tracking, and a responsive modern UI.


# 🚀 Features

## 👤 Authentication
- User Signup & Login
- JWT-based Authentication
- Secure Password Hashing using bcrypt
- Persistent Login Sessions

## 🍔 Product System
- Dynamic Product Loading from MongoDB
- Product Categories
- Product Detail Pages
- Ratings & Reviews
- Featured/Bestseller Products

## 🛒 Cart System
- Add/Remove Cart Items
- Persistent Cart Storage
- Cart Sync with Backend
- User-specific Cart Management

## 📦 Order System
- Real Checkout Flow
- Order Placement
- MongoDB Order Storage
- Order Tracking
- User Dashboard with Order History

## 🎨 Frontend
- React + Vite
- Tailwind CSS
- Framer Motion Animations
- Responsive Modern UI
- Zustand State Management

## ⚙️ Backend
- Flask REST API
- PyMongo Integration
- JWT Authentication
- Structured Backend Architecture
- Environment Variable Configuration

## ☁️ Database
- MongoDB Atlas Cloud Database
- Persistent User & Order Storage
